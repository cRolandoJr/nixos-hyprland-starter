# Tus fondos de escritorio

Esta carpeta se entrega sin imágenes. Copiá aquí fondos propios o con permisos
verificados, por ejemplo PNG, JPEG o WebP, y abrí el selector de Ryogami.
Home Manager configura tanto el daemon como el selector para usar esta ruta
bajo `~/projects/nix-config`. Sin imágenes, el selector estará vacío.

Git ignora los fondos personales de esta carpeta. No fuerces su incorporación
sin registrar autor, fuente y permiso de redistribución. No hay descarga automática.
Los fondos retirados están identificados en
[el inventario](../../docs/wallpapers-inventory.json); sus nombres no prueban autoría.
